Tips for Great Photos

  • 📷 Use good lighting - natural light works best
  • 🎨 Background will be automatically removed
  • 👔 Lay item flat or hang it
  • 📏 Capture the full item in frame
  • 🏷️ Make sure brand labels are visible and clear

AI Features (PoC)

To enable AI-powered clothing analysis: 

# Start all services (Ollama + rembg background removal)
docker compose up -d

# Pull AI models (first time only)
ollama pull llava:7b        # Fast model (default)
ollama pull llava:13b       # Enhanced brand detection (optional)

# Start the mockup server (serves files + AI API)
task mockups:dev

# Or manually:
cd mockups/api && go run main.go

Server runs on http://localhost:8556. Background removal happens automatically on upload. Use "✨ Detect with AI (13b)" button on item detail page for enhanced brand detection (2-3 min per image).
