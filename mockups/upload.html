AI Features (PoC)

To enable AI-powered clothing analysis: 

# Start Ollama and pull models (first time only)
ollama serve
ollama pull llava:7b        # Fast model (default)
ollama pull llava:13b       # Enhanced brand detection (optional, slower)

# Start the mockup server (serves files + AI API)
task mockups:dev

# Or manually:
cd mockups/api && go run main.go

Server runs on http://localhost:8556. Default uses fast 7b model. Use "✨ Detect with AI (13b)" button on item detail page for enhanced brand detection (2-3 min per image).
